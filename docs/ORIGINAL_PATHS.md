# Source organization and compatibility

`pipeline/`, `utils/` and `scripts/` contain the real categorized scripts. `code/` contains relative Git symlinks to those sources, retaining the original relative paths.
Neither the file contents nor the original workspace are modified.
Because symlink targets and real paths may differ, test imports, dynamic file access and shell scripts before relying on this layout.
